# PipeSpec v1

PipeSpec is a structured pipeline extraction format intended to be:

- platform-agnostic
- LLM-friendly
- schema-validatable
- suitable for downstream deterministic compilation (e.g. to OPOS)

PipeSpec focuses on describing *pipeline intent* (tasks, topology, I/O, integrations),
not embedding implementation payloads.

See **Quickstart** to validate example documents and integrate PipeSpec into your extraction workflow.
