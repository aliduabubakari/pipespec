# PipeSpec (v1)

**PipeSpec** is a platform-agnostic, LLM-friendly specification for representing data pipelines as structured, portable documents.

It provides a canonical orchestration skeleton that can be:

- generated by LLMs
- validated automatically
- transformed into execution plans for different orchestrators
- used for analysis, lineage, and reproducibility

## Design goals

PipeSpec is designed to be:

- **Platform-agnostic**  
  Not tied to Airflow, Prefect, Dagster, etc.

- **LLM-native**  
  Deterministic structure, low hallucination surface.

- **Composable**  
  Suitable for multi-pipeline systems and transformations.

- **Reproducible**  
  Versioned schema with strict validation.

- **Lineage-aware**  
  Explicit flow topology and integration catalogue.

## What PipeSpec captures

### Orchestration skeleton

- pipeline metadata
- task/component taxonomy
- executor types
- DAG topology (nodes + edges)

### Structured interfaces

- inputs / outputs
- parameters
- environment & secret references (never values)

### External integrations

- systems
- services
- storage
- APIs

### Coarse data lineage

---

## What PipeSpec deliberately does not include

PipeSpec does **not** embed:

- full SQL queries
- Python scripts
- business logic payloads

This keeps the specification:

- portable
- LLM-friendly
- diff-stable
- secure

---

## JSON and YAML support

Normative format:

*.pipespec.json

Validator convenience:

*.pipespec.yaml
*.pipespec.yml

YAML is converted to a Python dictionary and validated against the same JSON Schema.

```bash

Development setup

⸻

CLI usage

Validate a document:

pipespec-validate schema/examples/airvisual_pipeline.pipespec.json --semantic

Validate YAML:

pipespec-validate path/to/pipeline.pipespec.yaml --semantic

Exit codes

Code	Meaning
0	Valid
2	Invalid (parse or schema failure)


⸻

Version pinning for reproducibility

Always reference the versioned schema in research and production:

schema/pipespec_schema_v1.json

The non-versioned file is a moving alias.

Use cases

PipeSpec enables:
	•	LLM → pipeline generation
	•	cross-orchestrator translation
	•	pipeline catalogues
	•	static analysis of workflows
	•	lineage extraction
	•	reproducible research artefacts

⸻

Relationship to orchestration frameworks

PipeSpec is not a replacement for orchestrators.

It is an intermediate specification layer that can be compiled into:
	•	Airflow DAGs
	•	Prefect flows
	•	Dagster jobs
	•	Kubernetes pipelines
	•	custom runtimes
